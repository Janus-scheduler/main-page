<janus-timeline>

@janus-scheduler/ui since v1.0 stable

Renders resources as rows against a horizontal time axis, virtualising both directions. Owns drag, resize, zoom and conflict computation; reads its data from properties and reports changes as composed DOM events.

Limitation

<janus-timeline> virtualises rows, so it cannot be printed or exported to PDF directly — only the visible window exists in the DOM. Use SchedulerManager.snapshot() to render a full static grid for export. We do not plan to change this: keeping the whole range in the DOM would cost the performance the component exists for.
