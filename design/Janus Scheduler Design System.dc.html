06

Code and install blocks

Code blocks are always dark, in both themes — one syntax palette to maintain and one appearance developers recognise. The install block is the only element allowed a prompt glyph. Copy buttons are live: click one.

08

Callouts

Four kinds, distinguished by weight rather than colour alone. Limitation is deliberately the loudest: an inverted slab with a dashed edge, used only for honest scope disclosures — things Janus will not do. It should feel like the library speaking plainly, not a warning about misuse.

Light
Note

Times are stored as UTC instants. The view layer applies the display time zone at render.

Tip

Return a promise from event:drop and Janus will roll the move back if it rejects.

Warning

Mutating the events array in place bypasses change detection. Always pass a new reference.

Limitation

Janus does not implement recurrence expansion. Supply expanded instances from your own RRULE engine — we will not add one, because correct recurrence needs your calendar's semantics, not ours.
